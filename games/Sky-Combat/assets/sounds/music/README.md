# Music Assets

Place background music loops here. Referenced in `js/audio.js`.

| File | Used for |
|---|---|
| `music.mp3` / `music.ogg` | In-game background loop (plays during gameplay) |

Tips:
- Should be a seamless loop (start and end points aligned)
- Energetic/electronic genre fits the combat theme
- Keep under 5 MB — use 128 kbps MP3
